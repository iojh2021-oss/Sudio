# Sudio — استودیوی شهر سینمایی

موتور سه‌بعدی WebGL2 به‌صورت ماژول‌های JavaScript (بدون وابستگی، بدون اینترنت).

- شهر بی‌پایان و قطعه‌ای (۴۸ متر) که هنگام حرکت دوربین، با مه و محو‌شدن ساخته می‌شود؛ حتی در کیفیت پایین.
- ساختمان‌های واقعاً سه‌بعدی، خیابان سینمایی با پرسپکتیو، بازتاب زمین خیس، چراغ و نئون، مه و باران زنده.
- محیط‌های طبیعی بی‌پایان: جنگل، بیابان، برفی، دشت، ساحل (با دریا)، کوهستان؛ با نوشتن «در جنگل…» یا «کنار دریا…» ساخته می‌شود و با راه‌رفتن شخصیت ادامه پیدا می‌کند.
- شخصیت‌ها: افزودن، لمس برای راه‌رفتن، انیمیشن راه/دویدن/صحبت.
- صدای مرد، زن و کودک (سنتزکنندهٔ فورمانت داخلی، مثل تب استودیوی Bazi) + صدای سیستم در صورت وجود.
- متن ← صحنه: تحلیل‌گر قاعده‌محور فارسی/انگلیسی (آب‌وهوا، ساعت، شخصیت‌ها، حرکت، دیالوگ، دوربین).
- ضبط ویدیو (mp4/webm با صدا)، ذخیرهٔ خودکار، ذخیره/بارگذاری JSON، PWA.

## هوش مصنوعی واقعی (پس‌زمینهٔ متن‌به‌تصویر)
تب «🤖 هوش مصنوعی»: دو موتور متن‌باز.
- **Janus-Pro-1B** (deepseek-ai، ONNX از onnx-community) با Transformers.js روی WebGPU داخل مرورگر؛ حدود ۲٫۴ گیگابایت دانلود یک‌باره (کش می‌شود). نیاز: Chrome/Edge سازگار با WebGPU، اینترنت فقط برای دانلود اول.
- **سرور سازگار با AUTOMATIC1111** (`/sdapi/v1/txt2img`): مثل Local Dream/ComfyUI/Forge روی همان گوشی یا رایانه.
تصویر به‌صورت پس‌زمینهٔ دور پشت دنیای سه‌بعدی قرار می‌گیرد و با «ساخت خودکار هر ۶۰ متر» هنگام راه رفتن تازه می‌شود. آزمون خودکار با سرور ساختگی انجام شده؛ مدل واقعی در CI اجرا نمی‌شود.

## ساخت APK
تب Actions ← «Sudio APK» ← Run workflow. بعد از چند دقیقه فایل `Sudio.apk` در بخش Releases (برچسب `apk-latest`) و در Artifacts قرار می‌گیرد (APK آزمایشی با امضای debug؛ برای نصب مستقیم). برنامه با Capacitor دور همین سایت ساخته می‌شود. WebGPU (برای مدل هوش مصنوعی داخل برنامه) به نسخهٔ Android System WebView بستگی دارد؛ در غیر این صورت از موتور «سرور محلی» استفاده کن.

## محدودیت‌های صادقانه
- این مدل انتشار (diffusion) هوش مصنوعی نیست؛ «دستور متنی» با قواعد تحلیل می‌شود و صحنه را با موتور می‌سازد.
- صدای زن/کودک با تغییر زیروبمی و فورمانت ساخته می‌شود، نه صدای انسانی ضبط‌شده.

## اجرا
`python3 -m http.server` و باز کردن `index.html` (ماژول‌ها نیاز به http دارند). آزمون: `npm test`.
